# Smart Campus Energy Optimization Backend

This is a FastAPI-based backend service designed for smart campus energy optimization using linear programming (`PuLP`) and `OpenAI` integration.

## Tech Stack
- **Framework:** FastAPI
- **Optimization:** PuLP
- **AI Integration:** OpenAI API
- **Server:** Uvicorn
